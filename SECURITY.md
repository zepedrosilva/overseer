| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and privacy of Overseer and its users seriously.

If you discover a security vulnerability or potential sensitive data leakage, please report it privately:

1. **GitHub Security Advisory**: Open a private draft security advisory via the repository's **Security > Advisories > Report a vulnerability** tab.
2. **Direct Contact**: If unable to use GitHub Security Advisories, contact the repository maintainer directly via GitHub profile contact details.

**Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.**

### What to include in your report:
- A clear description of the vulnerability.
- Steps or a minimal proof of concept to reproduce the issue.
- Any potential impact on users, credentials, or local worktree state.

We will acknowledge receipt within 48 hours and work on a fix promptly.
